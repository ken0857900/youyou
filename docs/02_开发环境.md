# 开发环境搭建（Windows / Mac）

> 本地完整跑起来：数据库（PostgreSQL 17 + pgvector 向量 + zhparser 中文分词）→ 后端（FastAPI，第 5.5 节）→ 前端（Vite，第 5.6 节）。
> 只想快速跑一遍看 [README 快速开始](../README.md#快速开始)；这份写得更细，含常见问题。（2026-10-22 更新）

---

## 1. 安装 Git

**Windows**：到 https://git-scm.com/download/win 下载安装，选项一路默认即可。

**Mac**：打开「终端」，执行下面这行，按提示安装（会一起装好 Git）：

```bash
xcode-select --install
```

装好后确认：

```bash
git --version
```

---

## 2. 安装 Docker Desktop

数据库跑在 Docker 里，所有人的数据库环境才会完全一致。

**Windows**

1. 以管理员身份打开 PowerShell，执行 `wsl --install`，完成后**重启电脑**
2. 到 https://www.docker.com/products/docker-desktop/ 下载 Windows 版安装
3. 打开 Docker Desktop，等左下角显示 Engine running

**Mac**

1. 先确认芯片类型：左上角  →「关于本机」，看是 **Apple 芯片**（M1/M2/M3/M4）还是 **Intel**
2. 到 https://www.docker.com/products/docker-desktop/ 下载**对应芯片**的版本安装
3. 打开 Docker Desktop，等状态显示 running

> 两种芯片都能用：数据库镜像会在你自己的电脑上编译，已在 Intel 和 Apple 芯片两种架构上验证过。

**国内网络：配置镜像加速（建议做）**

基础镜像要从 Docker Hub 下载，国内经常很慢或失败。打开 Docker Desktop → Settings → Docker Engine，在 JSON 里加上 `registry-mirrors`（加速地址可以用阿里云「容器镜像服务」里的个人加速器地址，或其他当前可用的镜像源），然后点 Apply & restart：

```json
{
  "registry-mirrors": ["https://<你的加速地址>"]
}
```

装好后确认：

```bash
docker --version
docker compose version
```

## 3. 下载代码

仓库是私有的，需要先接受 GitHub 上的协作邀请。

```bash
git clone https://github.com/ken0857900/pathfinder.git
cd pathfinder
```

第一次 clone 时会要求登录 GitHub，按提示在浏览器里登录即可。

## 4. 准备环境变量

把范例文件复制成 `.env`（`.env` 不会被提交到 git）：

**Windows（PowerShell）**

```powershell
Copy-Item .env.example .env
```

**Mac**

```bash
cp .env.example .env
```

## 5. 启动数据库

```bash
docker compose up -d --build
```

第一次会下载基础镜像并编译中文分词，大约需要几分钟；之后再启动只要几秒。

**确认启动成功：**

```bash
docker compose exec db psql -U pathfinder -c "SELECT extname, extversion FROM pg_extension;"
```

看到 `vector` 和 `zhparser` 两行就代表成功。也可以试一下中文分词：

```bash
docker compose exec db psql -U pathfinder -c "SELECT to_tsvector('chinese', '北京大学计算机考研上岸');"
```

## 5.5 启动后端（FastAPI）

在仓库根目录执行（需要 Python 3.11；Windows 用 `backend\.venv\Scripts\python`，Mac 用 `backend/.venv/bin/python`）：

```bash
python -m venv backend/.venv
backend/.venv/Scripts/python -m pip install -r backend/requirements.txt
docker compose up -d
# 建表（seed.py 也会先执行这一步；不灌假数据时单独跑这行）
docker compose exec -T db psql -U pathfinder < backend/schema.sql
# 只给开发用：把前端 mock.js 的示例数据灌进库（会先执行 schema.sql 清空重建）
backend/.venv/Scripts/python backend/seed.py
# RAG：建 chunks 表，再给文章建向量索引（要 .env 里的 SILICONFLOW_API_KEY；没建索引搜索会是空的）
backend/.venv/Scripts/python -m RAG migrate
backend/.venv/Scripts/python -m RAG rebuild
cd backend && .venv/Scripts/python -m uvicorn app.main:app --port 8000
```

- 打开 http://localhost:8000/api/health 看到 `"db": "up"` 就是连上了；接口说明见 [09_接口文档](09_接口文档.md)，或打开 http://localhost:8000/docs
- 后端启动会读 `docs/07_提示詞.md`（提示词）和 `website/frontend/src/data/searchRules.json`（关键词规则），这两份不能少
- 要导入光华示例（线上那份）：`backend/.venv/Scripts/python backend/import_samples.py 示例.json`（每篇照真实发文流程抽决策点、建索引、跑保鲜度核验，会花 LLM 钱）
- 保鲜度：`cd backend && .venv/Scripts/python -m app.freshness crawl`（抓光华通知）／`index`（对文章抽主张）／`recheck`
- 改了 `agents.py` 或提示词后直接关掉重开后端；`--reload` 热重载卡住过（请求还是旧程序在回）
- 不要用 `pip install -e`（中文路径会让 venv 启动失败）；`requirements.txt` 里不要写中文（Windows 的 pip 用 GBK 读）

## 5.6 启动前端（Vite + React）

需要 Node.js 20.19+ 或 22.12+。

```bash
cd website/frontend
npm install
npm run dev          # 同 Wi-Fi 的手机要看：npm run dev -- --host
```

- 打开 http://localhost:5173 ；`/api`、`/uploads` 会自动转到 8000 端口（`vite.config.js` 的 proxy）
- 后端没开时前端退回 `src/data/mock.js` 的示例数据，画面照样能看
- 登录页下方「演示模式」不用注册就能登录

## 6. 常用指令

| 要做什么                | 指令                                                       |
| ----------------------- | ---------------------------------------------------------- |
| 启动数据库              | `docker compose up -d`                                   |
| 停止数据库（数据保留）  | `docker compose down`                                    |
| 进入数据库命令行        | `docker compose exec db psql -U pathfinder`              |
| 查看数据库日志          | `docker compose logs db`                                 |
| ⚠️ 清空本地数据库重来 | `docker compose down -v`（**会删掉本地所有数据**） |

数据库连接地址写在 `.env` 的 `DATABASE_URL`。线上服务器的数据库也是 Docker，只听本机，密码在服务器 `/opt/pathfinder/.db.env`。

## 7. 协作注意事项

- **换行符**：仓库用 `.gitattributes` 统一成 LF，Windows / Mac 混着改不会出现整份文件被改过的假 diff，不需要额外设置
- **不要提交 `.env`**：里面会放 API 密钥，已经在 `.gitignore` 里排除
- **文件名大小写要一致**：Windows 和 Mac 不区分大小写，但云服务器（Linux）区分。`import Home from './home'` 在本机能跑、上线就会坏

## 常见问题

**`docker compose up` 报 5432 端口被占用**
电脑上已经装过 PostgreSQL。把 `docker-compose.yml` 里的 `"5432:5432"` 改成 `"5433:5432"`，`.env` 里的 `localhost:5432` 也改成 `localhost:5433`。

**下载镜像很慢或失败**
检查第 2 步的镜像加速是否设置好。编译时还会从 GitHub 和 xunsearch.com 下载中文分词的源码，网络不稳时重新执行一次 `docker compose up -d --build` 即可。

**Windows 打开 Docker Desktop 报 WSL 相关错误**
以管理员身份在 PowerShell 执行 `wsl --update`，重启后再打开。
